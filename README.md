I'm a gameplay, tools and full-stack developer from Spain, mainly working with Unity and C#. I build gameplay systems, editor tools and practical workflows that make projects easier to develop and maintain.

<details>
  <summary><strong>Selected work</strong></summary>
  <br />

- [Beelze Pub](https://renhetstudio.itch.io/beelze-pub) - a cosy bartending and deduction game made with Renhet Studio for Comfy Jam: Summer.
- [Heredero del Oficio](https://bitem.itch.io/heredero-del-oficio) - a commissioned 2D graphic adventure developed for L'Alcora Town Council and winner of two awards.
- [Tricky Mansion](https://play.google.com/store/apps/details?id=com.ChapayPinturaJorgeRal.TrickyMansion) - a mobile horror game first built during a 48-hour game jam and later released on Google Play.
- [Unity Multimodal PCG Framework](https://github.com/bitemdev/Unity-Multimodal-PCG) - a modular Unity package combining procedural environments, entity spawning and procedural audio.
- [Unity Audio Engine](https://github.com/bitemdev/com.bitemdev.audio-engine) - designer-friendly Unity audio middleware with centralised events, pooled playback, music fades and mixer routing.
- [Designer Friendly Dialogue](https://github.com/bitemdev/DesignerFriendlyDialogueTool) - a free node-based dialogue editor and runtime for Unity and Godot.
- [Narrative Spreadsheet Importer](https://github.com/bitemdev/com.bitemdev.narrative-importer) - a Unity Editor tool that turns structured Google Sheets data into linked ScriptableObjects.
- [Renhet Studio website](https://renhetstudio.com/) - the official website for my indie game studio, built and maintained by me.
